# 強震モニタ揺れ検知 V3 設計書（近傍一致・PLUM 型）

V2（`kyoshinDetector.ts`：波面フィット＋リーキー積分＋逆投影系）を置き換える、**震源非依存の近傍一致検知**の設計。
JMA EEW（PLUM 法・着未着法）と Scratch 前身「リアルタイム地震ビューアー」の検知方式の調査から収束した結論に基づく。

> 関連: V2 設計書 `kyoshin-detection-design.md`。本書は検知コアの全面刷新であり、V2 コアを置換する。
> UI・音・自動タブ切替・自動フィット・地図オーバーレイ（`useKyoshinAlerts` / `deriveKyoshinView` /
> `RealtimeTab` / `KyoshinV2Overlay`）は V2 移行時（commit 3e02a27）のものを**流用**する。

## 1. 背景：なぜ作り替えるか

V2 は「波面フィットで震源を決め、その品質を時間積分して確信度を出す」設計だった。これが次の壁を生んだ:

- **Kanto の壁**: 弱い震度1の実地震（埼玉）と北関東の間欠ノイズが per-cluster 特徴（規模・振幅・連続性）で分離できない。
- **確定レイテンシ**: リーキー積分が S_ON まで登るのに 5〜6 秒。V1 の「2 連続フレーム確定」より遅い。
- **明滅**: クラスタ急成長中に波面フィットが一時破綻（fitOk=false）→ confirmed→weak へ転落→再確定（解除→再検知）。
- **分裂**: 1 地震が震央ジッタ・フィット失敗で複数イベント ID に割れる。
- **warmup**: LTA ベースラインが 60 秒間落ち着かず、コールドスタート直後は confirmed を出せない。

これらに band-aid（fast-confirm・片側拡張・連続性免除・確定ラッチ）を重ねたが、緩めるほど北関東の誤検知が出る堂々巡りになった。

## 2. 調査からの収束（JMA / Scratch 前身）

| | JMA（実物） | Scratch（前身） | V2（旧） |
|---|---|---|---|
| 検知の芯 | **PLUM**＝近傍観測点の実測震度で判定・震源不要 | **最短7点の近傍同時性**・震源不要 | 波面フィット＋積分＋逆投影 |
| ノイズ対策 | 着未着＋振幅分類 | **点別の静的しきい値**（1748点） | オンライン連続性ゲート |
| 震源 | IPF で別立て | EEW から（DM-D.S.S）別立て | 検知と一体化して破綻 |

**結論**: 検知から震源推定を切り離し、「**点別のノイズ床 ＋ 近傍同時性（PLUM 型の面）＋ 地域別の慢性活性ガード**」で検知する。
1 秒・計測震度という入力に最も噛み合い、Kanto の壁（**点別床＋地域活性の二軸**）・分裂（**近傍グラフ連結＋格子 ID**）・warmup（床は静的/長時定数＝LTA 追随不要）を原理から解消する。

## 3. 設計原則

1. **震源非依存**（source-free）: 検知の可否は「面として揺れが在り、近傍が同時に立ち上がったか」で決める。震源・波面フィットは検知に使わない（表示用の任意補助に降格）。
2. **点別の静的しきい値**: 観測点ごとに事前計算したノイズ床を持つ。ノイズの多い点（北関東・都市・火山）は自動的に鈍くなる。オンライン LTA を廃し **warmup を撤廃**。
3. **近傍同時性**: 点の検知は「その点の K 近傍のうち一定数が短時間窓で一緒に立ち上がった」ことを要件にする（PLUM／着未着の思想）。
4. **グループ化は近傍グラフ・格子は ID 専用**: イベントは K 近傍グラフの連結成分で束ねる（セル境界での分裂を避ける）。固定格子は安定 ID の錨としてのみ使う（同一地震が常に同一 ID）。
5. **速い・単純**: 強い per-frame 判別なので長い時間積分は不要。V1 相当（数秒）で確定。可動部を V2 より減らす。
6. **特異度は二軸で守る（単一防御にしない）**: (a) 点別のノイズ床（慢性的に騒がしい点を鈍く）＋ (b) セル別の慢性活性ガード（慢性活性な地域＝北関東等の確定バーを上げる）。北関東ノイズはコヒーレントに多点同時発火し得て近傍同時性(L2)を通過するため、床だけでは守れない。地域軸を独立に持つ（JMA の着未着＋振幅分類に相当する我々版の第2軸）。

## 4. 入力と制約

- 入力: Yahoo リアルタイム震度。約 1725 点・1 Hz・計測震度（`value = -3.0 + index*0.5`。震度0≈0.0）。
- サブ秒精度の到達時刻・P 波は無い。→ 波面フィット／到達時刻総当たりは原理的に不利（V2 で確認済み）。
- 観測点集合は `siteConfigId` で版が変わる。静的メタは**座標キー**（`siteKey(lat,lng)`）で引く。未知点は既定しきいで扱う。
- 純粋関数コア `step(state, frame, meta)` を維持。`meta` は静的（近傍・格子・任意の初期床 JSON）。点別床とセル慢性活性はオンライン学習で `state` 側（永続化対象）。

## 5. アーキテクチャ（層構成）

### L0 静的観測点メタ（オフライン事前計算・`meta`）

`public/data/` に JSON で持ち、初回に一度 fetch（生成データの遅延読込と同方式）。

- **点別しきい値 `siteThreshold[key]`**（計測震度 units）: 各点のノイズ床（ロバストな高分位点。例: 各点 `value` の 99 パーセンタイル）。Scratch の `ten:しきい` に相当。**取得は過剰リクエストを避ける**:
  - Yahoo の 1 リクエスト＝全 ~1725 点の 1 秒ぶん。床推定は点あたり数百〜2千サンプルで足りるので **~1〜2k フレーム（=~1〜2k リクエスト）を疎にサンプルした平常窓**で十分。**密な多日 1Hz 取得（10 万件超）は不要・不可**。この平常窓は検証（§10）で叩く窓と共用できる。
  - **本番はオンライン学習＋永続化が本命**（追加リクエスト 0）: ライブ受信 stream（既に 1 req/s 受信）から**長時定数（時間オーダー）の EWMA**で点別床を推定し localStorage に保存。V2 の LTA（45 秒）は追随が速すぎて慢性ノイズを捉えられなかったが、時間オーダーの時定数なら「その点が慢性的に騒がしい」を捉える。実イベント・群発で床が汚れ鈍化しないよう、床更新は **(i) 検知中の点・(ii) 近傍が同時活性の点で凍結**し、床に上限 `FLOOR_CAP` を設ける（改良4）。
  - コールドスタートは既定床 or 上記の小さな初期 JSON で開始し、稼働中に精緻化（→ warmup とは別。検知自体は初手から可能）。
  - 生成（初期 JSON・任意）: `scripts/build-station-thresholds.mjs`（疎サンプルのみ・スロットル付き）。
- **K 近傍 `neighbors[key]`**: 各点の最近傍 K 点（`R_km` 以内）。Scratch の「最短7点」に相当。
  - **生成は実行時**: `buildStationMeta(sites)` が受信中の実座標（Yahoo `sitelist.json`＝フレーム座標）から
    純粋な幾何計算で組む。近傍はメモリ上の座標から出せるため**追加リクエスト 0**。事前計算 JSON を出荷
    しないことで、`siteConfigId` 版差での `siteKey` ドリフト（JMA `station-coords` と Yahoo sitelist の
    不一致）を構造的に防ぐ。O(点数²) だが観測点集合ごとに一度だけ計算しキャッシュする（フレーム毎ではない）。
- **格子割当 `cellOf[key]`**: 各点が属する固定格子セル（緯度経度の等間隔ビン）。同じく `buildStationMeta` が実行時に算出。
- **セル別慢性活性 `cellActivity[cell]`**（オンライン学習・永続化・追加リクエスト 0）: 各固定格子セルが平常時にどれだけ「確定揺れ点」を出すかの長時定数の率。慢性活性セル（北関東等）で L4 の確定バーを上げる**第2の特異度軸**（§3-6・改良1）。

### L1 点トリガー（per-point, per-frame）

各点 `i` について:
- `level_i = value_i`
- `rate_i` = 直近 `RATE_DT`(2〜3s) での `value` 上昇量（1 フレーム差でなく**窓**で評価し、fetch ジッタ・欠測フレームを吸収。改良6）。
- **トリガー成立**: `level_i ≥ siteThreshold[i] + LEVEL_MARGIN` **かつ** `rate_i ≥ RATE_MIN`
  - level は「その点の床を超えたか」、rate は「今まさに立ち上がったか（オンセット）」。両者で持続ノイズと一過性を分ける。
- 欠測（`missing`）点はトリガー評価から除外し、`value` 履歴は最後の有効値で保持する。
- state: `triggeredAtMs[i]`（最終トリガー時刻）。`now − triggeredAtMs[i] ≤ TRIG_ACTIVE_MS` の間「トリガー継続」とみなす。

### L2 近傍同時性（core discriminator ＝ PLUM／着未着）

各トリガー継続点 `i` について:
- `agree_i` = K 近傍 `neighbors[i]` のうち `now − triggeredAtMs[neighbor] ≤ COINCIDENCE_MS` を満たす数。`avail_i` = `R_km` 以内に実在する近傍数。
- **「確定揺れ点（confirmed-shaking）」**: `agree_i ≥ MIN_NEIGHBORS` **または** `agree_i / max(avail_i,1) ≥ MIN_NEIGHBOR_FRAC`。
  - 実地震は点＋近傍が同時に立ち上がる。孤立・散在ノイズは近傍が揃わず脱落。
  - 疎地域（近傍が R_km 外・少数）は**割合条件**で救済し、離島・過疎網の小地震を取りこぼさない（改良5・§5-A 相当）。
- （Phase 2 任意・着未着精緻化）近傍のうち中心寄りが先に、外側が後にトリガーしている「外向き伝播」の整合を加点。1 秒量子化なので緩い判定に留める。Phase 1 では一致数のみ。

### L3 格子集約とイベント

- **グループ化＝K 近傍グラフの連結成分**（境界の無い方式。セル境界での分裂を避ける・改良3）。確定揺れ点どうしを近傍グラフで連結し、連結成分＝1 イベント。
- **ID 安定化＝固定格子（錨としてのみ）**。各成分に占有格子セル集合／重心セルで**安定 ID** を与え、前フレームとメンバー・セルが重なる成分は ID を継承。→ 分裂・明滅を構造的に防ぐ。
- **セル別慢性活性の更新**: 平常時に各セルが出す確定揺れ点率を長時定数で `cellActivity` に学習（実イベント中の該当セルは凍結）。
- イベント属性: メンバー確定揺れ点、占有セル、`maxIntensity`（メンバー現在 `value` 最大＝PLUM 出力）、初活性時刻、最終活性時刻。

### L4 確信度と発報

- **likely（可能性）**: 確定揺れ点 ≥ `MIN_LIKELY_POINTS`（例 3）**かつ** `maxIntensity ≥ MIN_LIKELY_INTENSITY`（例 震度1）。早期反応（候補音＋タブ）。
- **confirmed（検知）**: 確定揺れ点 ≥ `CONFIRM_POINTS`（例 5〜8・密度正規化＝改良5）**かつ** `maxIntensity ≥ MIN_CONFIRM_INTENSITY`（例 震度1、慢性活性セルは震度2）**かつ** `CONFIRM_FRAMES`（例 2）連続。→ V1 相当の速さで確定（積分待ちなし）。検知音＋タブ＋通知＋観測点フットプリントへ自動フィット。
- **震度ゲート（改良2）**: 低震度（震度0）の同時多発ノイズが点数だけで確定するのを防ぐ。JMA の発報基準（予報=震度3/警報=5弱）に倣った震度しきい。
- **地域活性バー（改良1・第2軸）**: `cellActivity` が高い（慢性活性）セルでは `CONFIRM_POINTS`・`MIN_CONFIRM_INTENSITY` を引き上げる。北関東のコヒーレントノイズが点別床をすり抜けても地域軸で受け止める。地域を名指しせず「慢性活性」で自動的に効く。
- **推定最大震度** = `maxIntensity` を震度階級へ。カード・音レベルに使用（`useKyoshinAlerts` のレベルアップ再鳴に供給）。
- **終了・保持**: セルが非活性化して `HOLD_MS`（例 10 秒）経過で解除（V1 相当の保持）。固定 ID なので明滅しない。
- **特異度＝二軸＋段階ゲート**: (a) 点別床（持続ノイズ）＋(b) セル別慢性活性（地域ノイズ）を独立軸に、L2 近傍同時性（散在排除）・点数集約（単点排除）・震度ゲート（低震度排除）を重ねる。単一防御にしない。

### L5 震源（任意・表示専用）

- 必要なら最早トリガー点近傍の重心を「推定震央（不確実）」として出す。**検知にも自動フィットにも使わない**（自動フィットはメンバー点のフットプリント）。深発・沖合は不確実として明示。

## 6. パラメータ初期値（ハーネスで較正）

| 記号 | 意味 | 初期値 |
|---|---|---|
| `LEVEL_MARGIN` | しきい床への上乗せ（value） | 0.5（≒ +震度0.5） |
| `RATE_MIN` | オンセット上昇量（value/RATE_DT） | 要較正（0.5 目安） |
| `RATE_DT` | 上昇量の評価間隔 | 2〜3 s |
| `K` | 近傍点数 | 7 |
| `R_km` | 近傍半径 | 40 km |
| `MIN_NEIGHBORS` | 近傍一致に要する数 | 3 |
| `COINCIDENCE_MS` | 近傍一致の時間窓 | 4 s |
| `TRIG_ACTIVE_MS` | トリガー継続窓 | 8 s |
| セル寸法 | 固定格子 | 0.2°（≒ 20 km） |
| `MIN_LIKELY_POINTS` | likely 点数 | 3 |
| `CONFIRM_POINTS` | confirmed 点数（密な網の上限） | 5 |
| `CONFIRM_DENSITY_FRAC` | 確定点数の密度正規化（疎地域救済） | 0.6 |
| `CONFIRM_FRAMES` | confirmed 連続フレーム | 2 |
| `MERGE_EVENT_KM` | イベント重心併合距離（分裂統合） | 100 km |
| `HOLD_MS` | 確定保持 | 10 s |
| しきい分位点 | 点別床算出 | 99 パーセンタイル（較正） |
| `MIN_NEIGHBOR_FRAC` | 近傍一致の割合条件（疎地域救済） | 0.5 |
| `MIN_LIKELY_INTENSITY` | likely の最大震度下限 | 震度1（value 0.5） |
| `MIN_CONFIRM_INTENSITY` | confirmed の最大震度下限 | 震度1（慢性活性セルは震度2） |
| `FLOOR_CAP` | 点別床の上限（鈍化防止） | 要較正 |
| `cellActivity` 時定数 | セル慢性活性の学習 | 時間オーダー |
| 慢性活性セル閾値 | 確定バー引き上げの発動 | 要較正 |

> パラメータは少数に保ち、可能なら物理から決め打つ（`R_km` は観測点間隔から、`COINCIDENCE_MS` は S 波速度 × `R_km` から）。少数の検証イベントへの過学習を避けるため検証は事件数を増やす。

## 7. 状態・純粋性・永続化

- `state`: 点別の `value` 短時間履歴・`triggeredAtMs`、点別床 `siteThreshold`（オンライン学習ぶん）、`cellActivity`（セル慢性活性）、アクティブイベント（ID・セル・メンバー）、ID 採番。
- `meta`（静的・不変）: `neighbors` / `cellOf` / 任意の初期床 JSON。
- **warmup 撤廃**: 床は静的/長時定数なので LTA の落ち着き待ちが無い。コールドスタート直後から検知可（V2 の 60 秒問題が消える）。
- **永続化対象**: 点別床・`cellActivity`・アクティブイベント（localStorage）。これで再読込・5 時リロード後も学習済みの床/地域活性を保つ（追加リクエスト 0）。

## 8. 出力とUI配線（既存流用）

- コアは既存 `DetectionEvent` 互換の配列を返す（`波面フィット系フィールドは削除`、`maxIntensity` を追加）。
  - 保持: `id` / `confidence` / `memberKeys` / `originTimeMs` / `lastOnsetAtMs` / `maxIntensity`(旧 lastPeak) / `lastSize`。
  - 削除: `epicenter`（→ 任意・null 可）/ `bearingDeg` / `oneSided` / `lastFitOk` / `radialFitOk` / `lastContiguity` / `strongStreak` / `score`。
- `deriveKyoshinView` / `useKyoshinAlerts` / `RealtimeTab` / `KyoshinV2Overlay` は概ね流用。
  - `RealtimeTab` の震度ヒストグラムは memberKeys から集計（現行踏襲）。
  - 片側配置の方位表示・score 表示は削除（震源を出さないため）。オーバーレイは「メンバー点の外周（フットプリント）」＋任意の推定震央に変更。

## 9. 計算量

- L1: O(点数) = 1725/フレーム。L2: O(点数 × K) ≈ 12k/フレーム。L3: 連結成分は活性点のみ（平常時ほぼ 0）。
- V2 の `spatialFill`（メンバー毎に全点走査）より大幅に軽い。1 Hz で余裕。

## 10. 検証計画（ハーネス `window.__fold`）

- **特異度**: 平常窓（北関東 12:00 / 03:00 / 14:30 / 18:00 ほか）で confirmed 0。**特に V2 の band-aid を壊した北関東コヒーレントバースト（[36.1,140.3] 型・震度1・9〜12点同時）を専用テストに据える**（点別床＋地域活性の二軸で 0 を確認）。
- **感度・速度**: 埼玉 M2.0 震度1 / 長野 M3.2 / 大隅 M5.2（沖）/ 福島沖 / 深発 / 疎地域（奄美・離島）などで、ネットワーク到達から数秒以内に confirmed・1 イベント・明滅なし。事件数を増やし過学習を避ける。
- **回帰**: 同時多発（離れた 2 地震）が別 ID に分離。**セル境界をまたぐ地震が 1 イベントに保たれる**（近傍グラフ連結・改良3）。
- 較正順: 床分位点/FLOOR_CAP → RATE_MIN → MIN_NEIGHBORS・MIN_NEIGHBOR_FRAC・COINCIDENCE_MS → CONFIRM_POINTS・震度ゲート → cellActivity 閾値。

### 10.1 実データ検証結果（2026-07-24・初回）

ハーネス `window.__fold`（履歴 RealTimeData を毎秒フェッチしてコア `step` にリプレイ）で確認:

- **感度・速度・非分裂・非明滅 ◎**: 福島県沖 2026-07-22 20:11（震度2・沖）を正のコントロールにリプレイ →
  likely 20:11:53 → **confirmed 20:11:54（1 フレーム後）**。単一イベント・明滅なし・重心 [37.24,140.98]≈真値 37.2N。
  波が広がるにつれ size 5→18。V2 の積分待ち（5〜6 秒）を解消し V1 相当の速さに戻った。
- **特異度 ◎**: 平常窓 03:00 / 12:00 / 14:30（各 180 秒・全国）で **confirmed 0・likely 0・近傍一致 0**。
  散在する単点ノイズは近傍が揃わず L2 で脱落する。
- **既知の限界（ユーザー合意済み・受容）**: 埼玉 M2.0 2026-07-22 08:00 は **単点の震度1 ブリップ**
  （観測点 35.7,139.8 が index 6→7＝震度0→1、近傍は震度0 据置）。同時刻に無関係な単点震度1 が全国に
  散在（相互 40km 外）。近傍一致（PLUM 型・≥3 近傍要求）は単点を**原理的に検知しない**——これは
  「全国の単点ノイズを弾く」特異度の軸そのもの。単点発火を許すとノイズ誤検知と不可分になるため、
  単点震度1 は検知対象外とし地図の生震度表示に委ねる（将来、学習済み点別床を大きく超えた単点に
  限った低確信度「単点の可能性」ティアは検討余地あり＝床の永続化が前提・§12）。
- **大隅 M5.2（07-17）はアーカイブ保持期間外の可能性**（未検証）。

### 10.2 永続化・地域ガードの検証（2026-07-24・2 回目）

- **永続化 ◎**: `extractLearned`/`hydrateLearned`＋フックの localStorage 読込/スロットル保存（60s）を実装。
  ライブ DMDSS で再読込後に `kyoshin-v3-learned` に点別床（148点）が保存・復元されることを確認。
  不連続リセット（初フレーム・欠測・巻き戻し）でも学習資産（床・`cellActivity`）を引き継ぐよう `ingest` を修正。
- **特異度（拡張）◎**: 平常〜日中の 5 時間帯（03:00 / 10:00 / 12:00 / 14:30 / 18:00・計 約50分・全国）で
  **confirmed 0・likely 0**。さらに**近傍一致（確定揺れ点）自体が 0**＝散在ノイズは L2 で完全に脱落。
  北関東ボックス（[35.7-36.7, 139.4-140.9]）を名指しで見ても誤検知 0。
- **地域ガード（`cellActivity`・第2軸）**: 単体テストで「慢性活性セルは震度1 コヒーレント同時多発を
  confirmed にしない／通常セルなら confirmed」を確認済み（機構は正しい）。**ただし実アーカイブ（07-22）では
  上記 5 窓で北関東ですら近傍一致が形成されず**、V2 の band-aid（fast-confirm がスコアを強制加点）を壊した
  種のコヒーレントバーストを再現できなかった。→ V3 の第1軸（点別床＋近傍一致＋点数/震度ゲート）だけで
  北関東を含む平常ノイズを弾けている。地域ガードは cellActivity が学習した後に効く**休眠中の安全網**として
  存置（本番の数日運用＋永続化で自然に学習）。実バーストでの発火抑制検証は、バースト捕捉時に持ち越し。

### 10.3 実地震マトリクス検証（2026-07-24・3 回目）＋ 2 つの改良

DMDATA カタログから多様な型の実地震を選び、Yahoo 履歴 RealTimeData をリプレイした結果、2 つの改良が必要と判明し取り込んだ:

- **改良a: 確定点数の密度正規化（`CONFIRM_DENSITY_FRAC`）**: 奄美大島近海 M4.7 震度3（疎島）が確定揺れ点
  最大 3 点で `CONFIRM_POINTS=5` に届かず likely 止まりだった。局所実在近傍数から確定点数を下げ、疎地域を救済。
