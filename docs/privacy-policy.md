# プライバシーポリシー

リアルタイム地震ビューアー（以下「本アプリ」）が扱う情報について説明します。

本アプリには**通常版**と**DM-D.S.S 版**（DMDATA.JP という配信サービスと直接つなぐ版）の 2 種類が
あります。以下で版を指定している項目は、その版をお使いの場合だけ当てはまります。

最終改訂: 2026年9月25日

## まとめ

- **本アプリは、利用者の情報を収集しません。** 開発者が受け取るものは何もありません
- **アクセス解析を入れていません。** 閲覧の記録を集める仕組みはありません
- 設定や表示の記録は、すべて**利用者の端末の中だけ**に保存されます
- 本アプリは情報を受け取るために外部のサービスへ接続します。その際、通常のウェブ閲覧と同じく、
  接続先には端末の IP アドレスなどが伝わります

## 1. 開発者が受け取る情報

**ありません。** 本アプリには、利用状況・閲覧履歴・端末の情報などを開発者へ送る仕組みが
ありません。アクセス解析サービス（Google Analytics 等）やエラー収集サービスも組み込んでいません。

本アプリはウェブサイトとして GitHub Pages で配信されているため、GitHub 社のサーバーには
アクセスの記録が残る可能性があります。これは GitHub 社が管理するもので、開発者は閲覧できません。

## 2. 端末の中に保存されるもの

次の情報が、ブラウザの保存領域に保存されます。
**いずれも端末の外へ出ることはありません。**

### 設定

表示・通知・読み上げなどの設定一式。次のものを含みます。

- **登録した地点の緯度・経度**（「ホーム地点」を設定した場合）
- **DMDATA.JP の API キー**（DM-D.S.S 版で入力した場合）
- **到達予想キー**（配布を受けて入力した場合）

### 表示の記録

- 行動チェックリストを畳んだ記録
- 閉じたお知らせの帯の記録
- 揺れ検知エンジンが観測点ごとに学習した値

### 受け取った情報の控え

同じ情報を何度も取りに行かないための控えです。一定の件数・容量・期間を超えたものから
自動的に消えます。

- 受け取った電文の原文（DM-D.S.S 版）
- 過去の電文のアーカイブ（DM-D.S.S 版）
- 地震活動の集計
- 揺れ検知の診断記録
- 取り込んだ強震波形データ（設定タブから読み込んだ場合）

### アプリ本体

オフラインでも動くよう、アプリのファイルがブラウザのキャッシュに保存されます。

## 3. 位置情報の扱い

設定タブで「現在地を取得」を押したときだけ、ブラウザの位置情報機能を使います。
その際ブラウザが許可を求めます。

- 取得した緯度・経度は**設定として端末内に保存されるだけ**で、どこへも送信されません
- 使いみちは、揺れの強さを判定する範囲の中心と、主要動の到達予想を出す地点の決定です
- 位置情報を使わなくても、本アプリのほかの機能はすべて利用できます
- 設定タブから削除できます

## 4. 入力したキーの扱い

次の 2 つは**暗号化されずに端末内へ保存されます**。共有の端末では利用にご注意ください。

- **DMDATA.JP の API キー**（DM-D.S.S 版）— DMDATA.JP へ接続するために使います
- **到達予想キー**（配布を受けた方のみ）— 一部の表示を切り替えるために使います

いずれも上記の用途にだけ使われ、開発者を含む第三者へ送信されることはありません。
不要になったら設定タブで消してください。

なお、設定の書き出し機能で作られるファイルに API キーは含まれません。

## 5. 接続する外部サービス

本アプリは次のサービスへ接続します。通常のウェブ閲覧と同じく、接続先には端末の
IP アドレス・ブラウザの種類などが伝わります。各サービスの扱いは、それぞれの
プライバシーポリシーをご確認ください。

| 接続先 | 目的 | いつ |
|---|---|---|
| [DMDATA.JP](https://dmdata.jp/) | 地震・津波・緊急地震速報の受信 | DM-D.S.S 版で API キーを設定したとき |
| [P2P地震情報](https://www.p2pquake.net/) | 地震・津波・緊急地震速報の受信 | 通常版の利用中つねに |
| [Yahoo!天気・災害](https://typhoon.yahoo.co.jp/weather/jp/earthquake/kyoshin/) | リアルタイム震度（強震モニタ）の受信 | 利用中つねに（毎秒） |
| Akamai（`time.akamai.com`） | 端末の時計のずれを補正 | 利用中つねに（数十秒ごと） |
| Esri（`tiles.arcgis.com`） | 海底地形の地図画像 | 地図に海底地形を表示しているとき。**録画モードを有効にしている間は、表示の設定にかかわらず地図画像を先に読み込みます** |
| GitHub Pages | アプリ本体と地図データの配信 | 起動時 |
| VOICEVOX | 読み上げの音声合成 | 読み上げを有効にしたとき。**接続先は利用者が指定します**（初期値はご自身の端末内） |

いずれの接続でも、本アプリが利用者を識別する情報を送ることはありません。

## 6. Cookie

本アプリは Cookie を使用していません。

## 7. 保存された情報の削除

ブラウザの設定から、本アプリのサイトデータを削除すると、上記のすべてが消えます。

- **Chrome / Edge**: 設定 → プライバシーとセキュリティ → サイトの設定 → 保存されているデータ
- **Safari**: 設定 → Safari → 詳細 → Web サイトデータ
- **Firefox**: 設定 → プライバシーとセキュリティ → Cookie とサイトデータ

設定タブの「ホーム地点」「DM-D.S.S 接続設定」からは、個別に削除できます。

## 8. お子様の利用について

本アプリは年齢を問わず利用できます。利用者の情報を収集しないため、年齢確認は行いません。

## 9. このポリシーの変更

内容を変更することがあります。変更後の内容は、本アプリに掲載した時点から適用されます。
